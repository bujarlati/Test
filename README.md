# Idle Forest

一个 Python 编写的挂机小游戏原型。玩法方向是 2D 横版森林自动砍怪，主角会持续前进、遇怪、战斗、掉落装备；装备变强后可以主动进入随机秘境挑战 Boss。

当前版本把玩法核心和表现层分开：

- Python 后端负责自动行走、刷怪、战斗、掉落、特殊套装、天赋、背包、市场和秘境。
- Web 原型负责用 Canvas 渲染森林和秘境地图，展示背包、已装备、市场、天赋、事件、秘境进度和宝箱怪保底。
- 微信小程序原型仍保留在 `miniprogram/`，但当前优先在网页上测试玩法。
- 装备稀有度预设为白、绿、蓝、紫、金、红，对应 `white/green/blue/purple/gold/red`。

## 运行 Web 原型

```powershell
python server.py --host 127.0.0.1 --port 8000
```

打开浏览器访问：

```text
http://127.0.0.1:8000/
```

网页会自动每秒推进挂机，也可以手动推进 10 秒、自动装备、进入秘境、离开秘境、买卖装备。

## 命令行 Demo

```powershell
python main.py --ticks 60 --auto-equip
```

## API 示例

- `GET /snapshot`：读取当前世界状态，适合前端轮询或初始化。
- `POST /tick`：推进挂机时间，body 示例：`{"seconds": 1}`。
- `POST /rift/enter`：进入已解锁秘境层，body 示例：`{"floor": 1}`；不传 `floor` 时进入当前最高解锁层。
- `POST /rift/leave`：主动离开当前秘境。
- `GET /talents`：读取完整天赋目录，目前 6 个等级共 900 个天赋。
- `POST /talent/evolve`：消耗 1 个天赋进化卷轴升级指定天赋，body 示例：`{"talent_id": "..."}`。
- `POST /equip-best`：自动穿上背包中评分更高的装备。
- `POST /equip-item`：穿戴指定背包装备，body 示例：`{"item_id": "..."}`。
- `GET /market`：读取交易市场挂单。
- `POST /market/list`：挂售背包装备，body 示例：`{"item_id": "...", "price": 120}`。
- `POST /market/buy`：购买挂单，body 示例：`{"listing_id": "...", "buyer_id": "player_1"}`。

本地 demo 会给主角一笔启动金币，并生成几件 NPC 市场挂单，方便直接验证购买流程。

## 秘境规则

- 初始解锁 1 层，通关 Boss 后解锁下一层。
- 每次进入秘境都会随机主题，目前有山洞、天空、城堡。
- 秘境前段会连续刷小怪，小怪清完后出现关底 Boss。
- 层数越高，怪物数值越强，小怪和 Boss 的掉宝率也越高。
- Boss 的掉宝概率显著高于普通小怪。
- 网页上会显示当前战力和推荐战力，但暂时不强制拦截挑战。

## 宝箱怪与特殊套装

- 普通森林挂机时有小概率遇到宝箱怪。
- 击败宝箱怪必定掉落一件特殊套装装备。
- 特殊套装也分白、绿、蓝、紫、金、红，红色自然掉落概率极低。
- 特殊装备可交易、可穿戴，并带有套装字段：套装名、部位名和 2 件套属性。
- 当前 2 件同套特殊装备会激活套装属性，增加攻击、防御和生命。
- 每击败 8 只宝箱怪会触发一次红色保底，额外掉落一件红色特殊套装装备，触发后计数重置。
- 网页上会显示宝箱怪遭遇率、红装保底进度和剩余次数。

## 天赋规则

- 创建角色时会自动抽取 3 个天赋。
- 天赋等级分为普通、优良、卓越、罕见、超凡、绝世。
- 每个等级当前生成 150 个天赋名称和对应属性加成，总计 900 个。
- 天赋可影响攻击、防御、生命、移动速度、装备掉宝率、金币、经验、宝箱怪遭遇率、秘境掉宝率和全属性。
- 低等级天赋抽取概率更高，绝世天赋开局概率极低。
- 打怪过程中有概率掉落天赋进化卷轴，宝箱怪和秘境 Boss 掉卷轴概率更高。
- 使用天赋进化卷轴会把指定天赋进化到下一等级，并在下一等级中随机获得一个新天赋。
- 绝世天赋不能继续进化。

## 项目结构

```text
idle_forest/
  config.py       # 稀有度、战斗、场景和秘境配置
  content.py      # 怪物、秘境主题、装备掉落和装饰生成
  engine.py       # 挂机世界主循环
  market.py       # 装备交易市场
  models.py       # 核心数据模型
  talents.py      # 天赋目录生成、抽取和进化
web/
  index.html      # 网页原型入口
  app.js          # 网页交互和 Canvas 渲染
  styles.css      # 网页样式
miniprogram/      # 微信小程序原型
main.py           # 命令行挂机 demo
server.py         # 标准库 HTTP API 和 Web 静态服务
tests/            # 核心逻辑测试
```

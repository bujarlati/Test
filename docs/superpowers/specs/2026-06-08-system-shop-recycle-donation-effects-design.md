# System Shop, Recycling, Donation Talents, and Premium Effects Design

## Goal

Make gold matter beyond player market purchases and reduce the value of repeatedly dying into overpowered monsters. Add long-term gold sinks, reliable equipment liquidation, and late-game talent growth while preserving the existing player market.

## Economy Features

### System Shop

Add a system shop separate from the player market.

- The player market remains player-to-player listings.
- The system shop sells fixed, expensive items for gold.
- Initial shop inventory includes:
  - rainbow equipment, stronger than red equipment
  - donation consumables used for late-game talent expansion
- Purchases are made from the current hero's gold and return an updated snapshot.
- Shop goods are generated by the server, not listed by players.

### Rainbow Equipment

Add a new rarity above red: `rainbow`.

- Rainbow equipment has stronger stats than red.
- Rainbow equipment uses a more spectacular palette and aura than red.
- Rainbow equipment is eligible for system shop purchases.
- Rainbow equipment can be equipped, previewed, and rendered by existing equipment systems.
- Rainbow items should not become a normal monster-drop rarity in this pass unless explicitly added later.

### Equipment Recycling

Add equipment recycling for items in the backpack.

- Each backpack item gets a recycle action.
- Recycling removes the item from inventory and grants gold equal to `score`.
- One-click recycle appears beside the backpack header.
- One-click recycle recycles all backpack items.
- Recycling never touches equipped items.
- Recycling never touches active market listings.
- Recycle events should appear in the event log and float as gold gain where appropriate.

### Selling Own Player-Market Listings To The System

Add a direct sell action for the player's own active market listings.

- The sell value is the listed item's `score`.
- It does not use the listing price.
- This prevents players from listing an item at an extreme price and converting half of that fake price into system gold.
- Selling removes the listing, removes the item from the market, and grants gold to the seller.
- Cancel listing remains available and returns the item to inventory without gold.

## Talent Expansion

Add donation-based talent expansion for late-game progression.

- A hero can use 5 donations only when all current talents are mythic.
- Using 5 donations adds one new random talent.
- The new talent starts at its rolled tier and can be evolved normally.
- When all talents are mythic again, the hero can spend 5 more donations to gain another new talent.
- This can repeat indefinitely.
- The hero snapshot exposes donation count and whether donation expansion is currently available.

## Premium Talent Effects

Add visually stronger talent effects using Pixellab-generated assets.

- Generate transparent pixel effects with Pixellab for:
  - lightning aura
  - flame aura
  - coiling dragon aura
- Use the effect assets as animated overlays tied to talent state.
- Effects should be more dramatic for mythic-heavy and rainbow-powered heroes.
- Keep the playfield readable: effects should frame the character rather than obscure the hero, monster, HP bars, or equipment.
- Use cache-busted asset URLs like the existing pixel assets.

## API Shape

Add server actions consistent with existing `POST` endpoints:

- `POST /shop/buy`
  - body: `{ "sku": "..." }`
  - buys system goods such as rainbow equipment or donations
- `POST /inventory/recycle`
  - body: `{ "item_id": "..." }`
  - recycles one backpack item for `score` gold
- `POST /inventory/recycle-all`
  - body: `{}`
  - recycles all backpack items
- `POST /market/sell-own`
  - body: `{ "listing_id": "..." }`
  - sells the player's own active listing to the system for item `score`
- `POST /talent/donate`
  - body: `{}`
  - spends 5 donations to add one random talent when all current talents are mythic

All endpoints return an updated snapshot.

## UI

Add one compact system-shop panel near the existing market/equipment area.

- The player market keeps its current role and layout.
- Backpack header gets a one-click recycle button.
- Backpack item cards add a recycle button beside equip/list.
- Own market listing cards show cancel and sell actions.
- Talent panel shows donation count and an expand button when all current talents are mythic.
- Rainbow rarity and premium effects get distinct styling but should not dominate the dashboard.

## Tests

Engine tests should cover:

- rainbow is stronger than red and purchasable with gold
- shop purchase fails without enough gold
- recycling one backpack item grants exactly `score`
- one-click recycle grants the sum of all backpack item scores
- recycling does not affect equipped items
- selling an own listing grants exactly item `score`, independent of listing price
- donation expansion requires all talents to be mythic
- donation expansion costs 5 donations and adds one talent

Server/account tests should cover:

- authenticated shop purchase, recycling, sell-own-listing, and donate routes save and return updated snapshots
- cross-account users cannot sell someone else's listing

Static frontend tests should cover:

- system shop UI is wired
- backpack one-click recycle exists
- item recycle action exists
- own market listing sell action exists
- donation expand button exists
- rainbow rarity labels/palette/effects are wired
- Pixellab talent effect assets exist and are cache-busted

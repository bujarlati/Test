# 微信小程序原型

这个目录是第一版微信小程序表现层。它不包含玩法逻辑，只负责：

- 轮询 Python 后端 `/tick` 推进挂机时间。
- 读取 `/snapshot`。
- 用 Canvas 渲染森林、主角、怪物、血条和最近掉落。
- 展示基础状态、背包、已装备、交易市场和战斗事件。
- 点击背包装备可以查看详情、穿戴或挂售。
- 点击市场挂单可以查看详情并购买非自己的装备。

## 本地联调

1. 启动后端：

   ```powershell
   python server.py --host 127.0.0.1 --port 8000
   ```

2. 用微信开发者工具打开项目根目录 `E:\IdelGame`。
3. 如果请求被拦截，在开发者工具中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。
4. 真机预览时，把 `miniprogram/app.js` 里的 `apiBase` 改成电脑局域网 IP，例如 `http://192.168.1.23:8000`，并启动后端时监听 `0.0.0.0`。

   ```powershell
   python server.py --host 0.0.0.0 --port 8000
   ```

生产环境需要 HTTPS 域名、微信登录、玩家存档和数据库；现在这版只用于快速打通玩法到客户端渲染。

当前后端是内存 demo：重启后数据会重置，市场会自动生成几件 NPC 挂单。
